# @selfcure/reporter

> HTML reporter for **selfcure** — renders test evidence (screenshots, traces, diffs) into a report.

Part of selfcure's **legacy BYOK pipeline**. Generates an HTML report plus a `summary.json` from the runner/heal output.

Internal library powering `selfcure report`. The headline, preventive flow is `selfcure lint` — see [`@selfcure/cli`](https://www.npmjs.com/package/@selfcure/cli).

## Install

```bash
npm install @selfcure/reporter
```
