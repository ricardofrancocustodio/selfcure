# @selfcure/web

> Local web UI for **selfcure** — testability dashboard, lint results, and one-click Pull Request flow.

Serves selfcure's browser UI: the `/lint` page shows scored components and ambiguous locators, lets you pick which `data-testid` fixes to include via checkboxes, and opens a Pull Request in one click (branch + commit + push + PR against your base branch).

Internal library powering `selfcure web`. See [`@selfcure/cli`](https://www.npmjs.com/package/@selfcure/cli).

## Install

```bash
npm install @selfcure/web
```
