Enterprise control requirements

  • Local-first source analysis with no mandatory cloud code upload.
  • GitHub Enterprise, GitLab, and Bitbucket flows through scoped OAuth or local CLI auth.
  • WCAG accessibility compliance gates and reporting.
  • Reviewable pull requests instead of direct production mutations.
  • Structured logs for compliance evidence and incident review.
  • Policy thresholds for CI, release gates, and platform scorecards.
  • Dedicated support, implementation review, and SLA packages for enterprise rollout.

Documentation and onboarding

Ready for platform-team rollout.
